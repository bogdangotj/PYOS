## 🚀 Возможности

| Возможность | Описание |
|-------------|----------|
| **Многопользовательская среда** | Регистрация, вход, смена пользователей (`su`), пароли Argon2id |
| **Три уровня прав** | ROOT / USER / PROGRAM на уровне потоков (`threading.local`) |
| **Виртуальные диски** | `C:`, `D:`, `E:` — создание и удаление смонтированных буквенных дисков |
| **Собственные приложения** | Форматы `.x4` (текст) и `.x4s` (LZMA-сжатый в RAM) |
| **X3-автоматизация** | Скрипты `.x3` с аргументами `$1`, `$2`, `$@`, переменными `$USER`, `$HOME`, `$CACHE` |
| **GitHub AppStore** | Установка приложений и команд прямо из репозитория на GitHub |
| **Целостность кода** | Проверка Argon2id-хеша при старте, откат из бэкапа при модификации |
| **Бэкапы** | LZMA Extreme + Argon2id, автосохранение при старте/выключении/часу |
| **Корзина с сжатием** | Удалённые файлы хранятся в `/sysdata/trash`, очистка с архивацией в `.tar.xz` |
| **Уведомления и таймеры** | Центр уведомлений с бэйджами, фоновые асинхронные таймеры |
| **UAC** | 4 уровня: строгий, стандартный, слабый, отключён |
| **Shell** | Цветной терминал, автодополнение Tab, подсказки при опечатках, `man <команда>` |
| **Редактор** | Встроенный консольный редактор PyEdit (`edit` / `nano`) |
| **Защита от tar-slip** | Валидация путей при извлечении архивов |

## 🔒 Архитектура безопасности

### 1. Argon2id + Salt
PyOS использует алгоритм **Argon2id** (памятноёмкий, устойчивый к GPU/ASIC атакам) для:
* Хеширования и проверки паролей пользователей (`PasswordHasher`).
* Подписи и верификации целостности самого файла ОС. При старте система проверяет метаданные из `.pyos`, сравнивает Argon2id-хеш исходника и при обнаружении сторонних модификаций запрашивает подтверждение или предлагает восстановление из бэкапа.
* Защиты паролей к защищённым папкам пользователей.
