## 🔒 Архитектура безопасности

### 1. Argon2id + Salt
PyOS использует алгоритм **Argon2id** (памятно-емкий и устойчивый к атакам на GPU/ASIC) для:
* Хеширования и проверки паролей пользователей системы (`PasswordHasher`).
* Подписи и верификации целостности самого файла ОС. При старте система проверяет метаданные из `.pyos`, сравнивает Argon2id-хеш исходника и при обнаружении сторонних модификаций запрашивает подтверждение либо предлагает автоматическое восстановление из бэкапа.

### 2. AST-Валидатор кода (`X4ASTValidator`)
Все запускаемые сторонние приложения (`.x4` / `.x4s`) перед исполнением проходят динамический разбор и статический анализ AST-дерева (`ast.NodeVisitor`). 

**Строго запрещены:**
* Конструкции: `import`, `ImportFrom`, `ClassDef`, `AsyncFunctionDef`, `Global`, `Nonlocal`, `Await`.
* Опасные встроенные имена: `__builtins__`, `__import__`, `exec`, `compile`, `open`, `globals`, `locals`, `vars`, `dir`, `getattr`, `setattr`, `delattr`.
* Доступ к dunder-атрибутам (`__class__`, `__subclasses__` и др.).
* Опасные строковые методы: `.format()`, `.format_map()`.

### 3. Безопасный вычислятель (`safe_eval`)
Математические выражения и строковые операторы обрабатываются изолированным вычислятелем на базе AST, ограниченным встроенным списком допустимых математических функций из модуля `math`.

## 🛡️ Система разграничения прав (Nexus)

Вся работа подсистем PyOS строго контролируется контекстом прав `PermissionContext` на уровне потоков (`threading.local`):

| Уровень прав | Значение | Описание и ограничения |
| :--- | :---: | :--- |
| **Perm.ROOT** | `3` | Ядро ОС. Имеет абсолютный доступ ко всем файлам, системным директориям `/sysdata` и конфигурациям. Недоступен напрямую пользовательскому коду. |
| **Perm.USER** | `2` | Авторизованный пользователь. Разрешён доступ к домашней директории `/home/<user>`, доступ на чтение системных программ. Запрещена запись в `/sysdata` и чужие домашние папки. |
| **Perm.PROGRAM** | `1` | Изолированное приложение. Имеет доступ **только** к своей папке данных `/apps/data/<app_name>` и своему кэшу `/cache/<app_name>_*`. |
| **Perm.NONE** | `0` | Неавторизованные фоновые потоки. Доступ к FS заблокирован. |

## 🗂️ Виртуальная файловая система (RealFS)

* **Поддержка виртуальных дисков**: Возможность монтирования буквенных дисков (`C:`, `D:`, `E:` и т.д.).
* **Файловый индексатор**: Потокобезопасный фоновый индекс (`_ilock`), обеспечивающий мгновенный поиск файлов через `find`.
* **Безопасная корзина (`TrashManager`)**:
  * Удаление файлов перемещает их в мета-структуру `/sysdata/trash` с присвоением ID.
  * Очистка корзины может автоматически сжимать удалённые объекты в ультра-сжатый `.tar.xz` архив в директорию `/cache/trash_archives`.
* **Защита от Tar-Slip**: Все функции работы с архивами проверяются специальным валидатором путей `_safe_join`.

## 📦 Форматы файлов и приложений (.x4 / .x4s)

PyOS поддерживает собственную спецификацию программного обеспечения:

### Текстовый формат `.x4`
Состоит из четырёх явных секций:
```ini
[INFO]
name: app_name
description: Описание программы
version: 1.0.0
author: Author Name
tag: Technical
background: false

[CODE]
# Валидный Python-код, прошедший X4ASTValidator
print("Hello from X4 App!")
[/CODE]

[DATA]
folder: /apps/data/app_name
[/DATA]

[OTHER]
Free License -- Kostyl Studios
[/OTHER]
[END]

Сжатый формат .x4s
Представляет собой бинарный файл, сжатый алгоритмом LZMA (Extreme preset). При запуске распаковывается непосредственно в RAM в миллисекундный срок без создания временных файлов на диске.
API среды исполнения X4 Runtime
Внутри кода .x4 доступны безопасные функции:
 * print_color(text, color), clear(), sleep(sec) — консольный вывод и управление.
 * notify(title, msg), notify_high(title, msg) — отправка системных уведомлений.
 * request_user(reason) — запрос повышения прав до уровня Perm.USER через UAC.
 * fwrite(), fappend(), fread(), fexists(), fdelete(), fmkdir(), flist() — изолированная работа с ФС.
 * cache_write(), cache_read(), cache_has(), cache_del() — быстрый доступ к кэшу.
 * spawn_thread(), background(), sysinfo() — системные утилиты среды.
⚡ Интерпретатор автоматизации (.x3)
Скрипты .x3 предназначены для пакетного выполнения цепочки команд PyOS.
 * Аргументы: Поддержка позиционных параметров $1, $2, ..., $@, а также глобальных переменных $USER, $HOME, $CACHE.
 * Рекурсивный вызов: Защита от бесконечной рекурсии (лимит глубины вызова: 10 уровней).
 * Режимы скорости:
   * normal — выполнение с визуальной паузой для отслеживания шагов.
   * --fast — мгновенное пакетное выполнение без задержек.
📡 Фоновые службы и Guard подсистемы
 * FSHealthChecker: Фоновый поток, проверяющий физическую целостность структур системных папок каждые 2.5 секунды. В случае удаления системной папки вызывает эмуляцию BSOD (Blue Screen of Death).
 * Guardian:
   * Контроль суточных лимитов сессий.
   * Автоматическая очистка и оптимизация дискового пространства папок приложений /apps/data/ при превышении заданного квотирования.
   * Интеграция с GitHub API для проверки и обновлений ядра ОС и приложений.
 * NotificationCenter & TimerService:
   * Система приоритетных уведомлений с визуальными бэйджами.
   * Поддержка фоновых асинхронных таймеров с оповещениями.
 * AppBackgroundManager: Служба регистрации и контроля приложений, работающих в фоновом режиме.
🛡️ Контроль учётных записей (UAC)
Система UAC регулирует выдачу прав уровня USER и ROOT для программ и системных действий:
 * Уровень 1 (Строгий): Запрашивает пароль текущего пользователя при каждом повышении прав.
 * Уровень 2 (Стандартный): Запрашивает интерактивное подтверждение (y/n).
 * Уровень 3 (Слабый): Выдаёт права USER автоматически, но требует подтверждения для ROOT.
 * Уровень 4 (Отключено): Автоматическое предоставление прав без вопросов.
🚀 Установка и запуск
1. Установка зависимостей
Для работы криптографического модуля Argon2id требуется пакет argon2-cffi:
pip install argon2-cffi

2. Запуск системы
python pyos.py

3. Первоначальный запуск
При первом запуске PyOS предложит выбрать режим настройки:
 * Автоматический (auto): Создаст компьютер Computer, пользователя User без пароля, заведёт стандартные диски и установит встроенные утилиты (calc, notes, guess, hello).
 * Ручной (manual): Позволяет задать индивидуальное имя хоста, логин, надежный Argon2id-пароль и подсказку.
💻 Полный справочник команд Shell
Файловая система и навигация
 * ls [-a] [-l] [path] — просмотр содержимого каталога с цветовой индикацией видов файлов.
 * cd <path | ~ | - | DISK:path> — смена текущего каталога или диска.
 * pwd — вывод текущего виртуального пути.
 * mkdir <path> — создание директории.
 * rmdir <path> — безопасное удаление директории в корзину.
 * touch <file> — создание пустого файла или обновление времени изменения.
 * rm [-r] [--perm] <file> — удаление файла в корзину (или навсегда при --perm).
 * cat <file> — вывод содержимого текстового файла.
 * cp <src> <dst> — копирование файла или папки.
 * mv <src> <dst> — перемещение файла или папки.
 * rename <file> <new_name> — переименование объекта.
 * find [path] <pattern> — мгновенный поиск файлов по индексу.
 * grep <pattern> <file> — поиск текста внутри файла с подсветкой.
 * wc <file> — подсчёт строк, слов и байтов в файле.
 * tree [path] — отображение дерева каталогов.
 * du [path] — размер файла или папки.
 * df — занятое пространство на всех смонтированных дисках.
Приложения и GitHub AppStore
 * app store — интерактивный магазин приложений с GitHub API.
 * app tags — просмотр установленных программ, отсортированных по категориям/тегам.
 * app manager — управление установкой, удалением, сжатием (disable) и разжатием (enable).
 * app list — список всех активных и отключенных приложений.
 * app run <name> — запуск программы.
 * app install <file> — установка файла .x4 или .x4s.
 * newapp <name> [tag] — генерация шаблона приложения в папку Documents.
Автоматизация (.x3)
 * x3 [--fast] <file.x3> [args] — запуск скрипта автоматизации.
 * newx3 <name> — генерация шаблона .x3 в папку Documents.
Администратирование пользователей
 * whoami — имя текущего пользователя.
 * id [user] — идентификаторы, статус пароля и домашний диск.
 * su <user> — переключение на другого пользователя.
 * users — список всех пользователей системы.
 * useradd <name> — создание нового пользователя (требует ROOT/UAC).
 * userdel <name> — удаление пользователя и его файлов (требует ROOT/UAC).
 * passwd — смена или удаление пароля текущего пользователя.
Безопасность, Обновления и Бэкапы
 * uac [1-4] — просмотр и изменение уровня UAC.
 * perms — просмотр таблицы прав Nexus и правил AST-валидатора.
 * guardian — центр безопасности, ручная оптимизация и удаление ОС.
 * guardian github — проверка и авто-обновление ядра ОС прямо из репозитория GitHub.
 * backup list — список резервных копий.
 * backup create [name] — создание LZMA-бэкапа всей системы и исходного кода.
 * backup restore <name> — восстановление системы из копии.
Настройки и Обслуживание
 * settings — панель конфигурации (язык, режим бэкапа, UAC, отладка).
 * smartmem [on|off|clean] — управление умной очисткой пустых логов и временных каталогов.
 * trash [list|empty|restore|rm] — управление корзиной.
 * cache [list|clear|cat|rm] — управление дисковым кэшем.
 * notif [read|clear] — просмотр и очистка уведомлений.
 * timer [add|cancel|clear] — управление таймерами.
 * debug [clear] — просмотр логов системных ошибок и паник ядра.
 * sysinfo — подробный сводный отчет о системе и ресурсах.
 * edit <file> — встроенный консольный текстовый редактор PyEdit.
 * man <cmd> — просмотр подробного руководства по любой команде.
📂 Структура директорий ОС
Системная папка создаётся в директории запуска и имеет следующую иерархию:
<Компьютер>/
└── C:/
    ├── home/
    │   └── <User>/
    │       ├── Desktop/
    │       └── Documents/
    ├── sysdata/             # [Perm.ROOT] Данные системы, хеши, корзина
    │   ├── trash/
    │   ├── trash_index.json
    │   ├── errors.json
    │   └── pyos_state.json
    ├── cache/               # Временный кэш приложений и архивы
    │   ├── deleted_apps/
    │   └── trash_archives/
    └── apps/
        ├── installed/       # Установленные бинарники .x4 / .x4s
        ├── data/            # [Perm.PROGRAM] Изолированные папки данных
        ├── store/           # Загруженные пакеты из AppStore
        └── logs/            # Краш-логи упавших приложений
