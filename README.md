## 🔒 Архитектура безопасности

### 1. Argon2id + Salt
PyOS использует алгоритм **Argon2id** (памятноёмкий, устойчивый к GPU/ASIC атакам) для:
* Хеширования и проверки паролей пользователей (`PasswordHasher`).
* Подписи и верификации целостности самого файла ОС. При старте система проверяет метаданные из `.pyos`, сравнивает Argon2id-хеш исходника и при обнаружении сторонних модификаций запрашивает подтверждение или предлагает восстановление из бэкапа.
* Защиты паролей к защищённым папкам пользователей.

### 2. AST-Валидатор кода (`X4ASTValidator`)
Все запускаемые сторонние приложения (`.x4` / `.x4s`) перед исполнением проходят статический анализ AST-дерева (`ast.NodeVisitor`).

**Строго запрещены:**
* Конструкции: `import`, `from ... import`, `class`, `async def`, `global`, `nonlocal`, `await`.
* Опасные встроенные имена: `__builtins__`, `__import__`, `exec`, `compile`, `open`, `globals`, `locals`, `vars`, `dir`, `getattr`, `setattr`, `delattr`.
* Доступ к dunder-атрибутам (`__class__`, `__subclasses__` и др.).
* Опасные строковые методы: `.format()`, `.format_map()`.

### 3. Безопасный вычислятель (`safe_eval`)
Математические выражения обрабатываются изолированным вычислятелем на базе AST, ограниченным белым списком допустимых математических функций из модуля `math`. Функция `eval` в среде приложений — это безопасный алиас на `safe_eval`.

## 🛡️ Система разграничения прав (Nexus)

Вся работа подсистем PyOS строго контролируется контекстом прав `PermissionContext` на уровне потоков (`threading.local`):

| Уровень прав | Значение | Описание и ограничения |
|:---|:---:|:---|
| **Perm.ROOT** | `3` | Ядро ОС. Абсолютный доступ ко всем файлам и системным директориям. |
| **Perm.USER** | `2` | Авторизованный пользователь. Доступ к `/home/<user>`, запрет на запись в `/sysdata` и чужие домашние папки. |
| **Perm.PROGRAM** | `1` | Изолированное приложение. Доступ только к своей папке `/apps/data/<app>` и кэшу `/cache/<app>_*`. |
| **Perm.NONE** | `0` | Фоновые потоки без доступа к файловой системе. |

## 🗂️ Виртуальная файловая система (RealFS)

* **Виртуальные диски**: монтирование буквенных дисков (`C:`, `D:`, `E:` и т.д.).
* **Файловый индексатор**: потокобезопасный фоновый индекс для мгновенного поиска через `find`.
* **Безопасная корзина (`TrashManager`)**: удалённые файлы перемещаются в `/sysdata/trash` с ID; очистка может сжимать объекты в `.tar.xz` в `/cache/trash_archives`.
* **Защита от Tar-Slip**: все функции работы с архивами проверяются валидатором путей `_safe_join`.

## 📦 Форматы файлов и приложений (.x4 / .x4s)

PyOS поддерживает собственную спецификацию ПО.

### Текстовый формат `.x4`
Состоит из секций `[INFO]`, `[CODE]`, `[DATA]`, `[OTHER]`, `[END]`:

```ini
[INFO]
name: app_name
description: Описание программы
version: 1.0.0
author: Author Name
tag: Technical
background: false

[CODE]
# Валидный Python-код, прошедший X4ASTValidator
print("Hello from X4 App!")
[/CODE]

[DATA]
folder: /apps/data/app_name
[/DATA]

[OTHER]
Free License -- Kostyl Studios
[/OTHER]
[END]
```

### Сжатый формат `.x4s`
Бинарный файл, сжатый алгоритмом LZMA (Extreme preset). При запуске распаковывается в RAM без создания временных файлов на диске.

**API среды исполнения X4 Runtime:**
* `print_color(text, color)`, `clear()`, `sleep(sec)` — консольный вывод.
* `notify(title, msg)`, `notify_high(title, msg)` — системные уведомления.
* `request_user(reason)` — запрос прав `USER` через UAC.
* `fwrite()`, `fappend()`, `fread()`, `fexists()`, `fdelete()`, `fmkdir()`, `flist()` — изолированная работа с ФС.
* `cache_write()`, `cache_read()`, `cache_has()`, `cache_del()` — кэш приложения.
* `spawn_thread()`, `background()`, `sysinfo()` — системные утилиты.

## 🕹️ Интерпретатор автоматизации (.x3)

Скрипты `.x3` для пакетного выполнения цепочки команд PyOS:

* **Аргументы**: `$1`, `$2`, ..., `$@`, `$USER`, `$HOME`, `$CACHE`.
* **Рекурсия**: защита от бесконечной рекурсии (лимит глубины — 10 уровней).
* **Режимы**: `normal` (с паузами) и `--fast` (без задержек).
* Команды: `x3 [--fast] <file.x3> [args]`, `newx3 <name>`.

## ⚙️ Фоновые службы и Safety-центр

* **FSHealthChecker**: фоновый поток, проверяющий целостность системных папок каждые 2.5 секунды. При удалении — эмуляция BSOD.
* **Safety**: контроль суточных лимитов сессий, оптимизация папок приложений, интеграция с GitHub API для обновлений ядра.
* **NotificationCenter & TimerService**: приоритетные уведомления с бэйджами, фоновые асинхронные таймеры.
* **AppBackgroundManager**: регистрация и контроль фоновых приложений.

---

## 🛡️ Контроль учётных записей (UAC)

Система UAC регулирует выдачу прав `USER` и `ROOT`:

* **Уровень 1 (Строгий)**: пароль пользователя при каждом повышении прав.
* **Уровень 2 (Стандартный)**: интерактивное подтверждение (y/n).
* **Уровень 3 (Слабый)**: права `USER` автоматически, `ROOT` — с подтверждением.
* **Уровень 4 (Отключено)**: автоматические права без вопросов.

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install argon2-cffi
```

### 2. Запуск системы
```bash
python pyos.py
```

### 3. Первоначальный запуск
При первом запуске PyOS предложит:
1. Выбрать язык (`ru` / `en`).
2. Прочитать и принять лицензию MIT (скачивается с GitHub, при отсутствии интернета — встроенный fallback-текст).
3. Выбрать режим настройки: автоматический (создаёт компьютер `Computer`, пользователя `User`) или ручной (индивидуальное имя хоста, логин, пароль).

## 📂 Структура директорий ОС

```
<Компьютер>/
└── C:/
    ├── home/
    │   └── <User>/
    │       ├── Desktop/
    │       └── Documents/
    ├── sysdata/             # [Perm.ROOT] данные системы, хеши, корзина
    │   ├── trash/
    │   ├── trash_index.json
    │   ├── errors.json
    │   └── pyos_state.json
    ├── cache/               # временный кэш приложений и архивы
    │   ├── deleted_apps/
    │   └── trash_archives/
    └── apps/
        ├── installed/       # установленные бинарники .x4 / .x4s
        ├── data/            # [Perm.PROGRAM] изолированные папки данных
        ├── store/           # пакеты из AppStore
        └── logs/            # краш-логи приложений
```
