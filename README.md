## 🌟 Общая информация

**PyOS v18.2 "Sentry"** — это уникальная модульная операционная система, работающая прямо внутри интерпретатора Python. Проект сочетает в себе полноценную виртуальную файловую систему (RealFS), изолированную среду выполнения приложений (X4/X4S в песочнице PROGRAM), контроль доступа на базе ролей (ROOT, USER, PROGRAM), а также настраиваемую систему контроля учётных записей (**UAC**), вдохновленную классическими дексктопными ОС.

---

## 🚀 Ключевые особенности

### 🔒 Безопасность и защита
* **Argon2id + Salt:** Надежное хэширование паролей и криптографическая проверка целостности исходного кода для защиты от несанкционированных модификаций.
* **AST Security Validator:** Инспектор синтаксического дерева Python, блокирующий опасные конструкции в приложениях (`import`, `exec`, `open`, доступ к `__globals__` и dunder-методам).
* **Система UAC (Контроль учётных записей):** 4 уровня безопасности для подтверждения привилегированных действий (от строгого ввода пароля до полностью автономного режима).

### 🗂️ Файловая система и данные
* **Многоуровневые права доступа:** Четкое разделение прав между ядром (ROOT), пользователем (USER) и сторонними программами (PROGRAM).
* **Защищенная корзина (Trash):** Удаленные файлы попадают в изолированное хранилище с возможностью восстановления или сжатия в архивы `tar.xz`.
* **Smart Memory:** Автоматическая очистка пустых логов, временных папок и кэша.

### 📦 Приложения и Автоматизация
* **X4 & X4S Архивы:** Формат приложений с метаданными, изоляцией данных (`/apps/data/<app>`) и поддержкой LZMA-сжатия.
* **X3 Automation Scripts:** Встроенный интерпретатор скриптов автоматизации (.x3) для последовательного выполнения команд в терминале.

### 🌐 Облачная интеграция с GitHub
* Прямая связь с репозиторием `bogdangotj/PYOS`.
* Команда `guardian github` проверяет наличие новых версий через `version.json`, скачивает свежий код и безопасно обновляет систему «на лету» с созданием резервной копии.

## ⚙️ Уровни контроля UAC

В PyOS встроено 4 уровня безопасности (управляются командой `uac <1-4>` или через `settings uac`):

| Уровень | Название | Описание |
| :---: | :--- | :--- |
| **1** | **Строгий** | Требует введения пароля пользователя для подтверждения всех `USER` и `ROOT` запросов. |
| **2** | **Стандартный** | Классический режим с подтверждением через диалог `(y/n)` без ввода пароля *(по умолчанию)*. |
| **3** | **Слабый** | Права `USER` выдаются автоматически (с уведомлением), запросы `ROOT` требуют подтверждения. |
| **4** | **Отключено** | Полное отсутствие запросов: все права выдаются автоматически с информационными плашками. |
